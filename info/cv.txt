SECTION: Research Projects

ITEM: Learning-Based Control and Imitation for Human-Centered Robotics
BULLET: [IEEE IROS 2025] FABRIC: An AI toolkit for fully 3D-printable, 22-DOF expressive robots using learning from demonstration. Enabled visual programming and achieved 90.17% ASL word/phrase execution and approximately 85% ASL alphabet execution.
BULLET: [Submitted to ISMAR 2026] Expressive signing avatars: Trained PPO + GAIL policies on 18,495 ASL videos with parametric emotion modeling to generate expressive head motion, improving user-rated experience and social realism (p < 0.05, N = 95).
BULLET: Configurable SCARA robot: Developed DDPG-based trajectory learning via inverse kinematics in NVIDIA Isaac Sim, achieving 97.8% target-reaching accuracy with sim-to-real policy transfer. Open-sourced the system.

ITEM: Autonomous Robotics in Unstructured Environments
BULLET: [IEEE NICS 2022] Tokai: A low-cost autonomous waste-collection robot integrating object detection, off-board vision, and onboard control. Achieved 99.52% mAP and real-time perception above 30 FPS on a $98 hardware stack.
BULLET: [IEEE AMS 2017] Mars rover: Developed a rover with a 6-DOF manipulator, inverse kinematics, and GPS-based autonomous navigation using Haversine path planning and PID control. Achieved 1 km terrain traversal with 0.20–4.10 m endpoint error; ranked 6th of 93 teams (top 6.5%) at URC 2018.

ITEM: Demonstration-Based Robot Programming and Mechanism Design
BULLET: [ACM CHI 2022] Mobiot: A human–AI collaborative system for designing 3D-printable robots from smartphone demonstrations. Achieved less than 1% motion error in target reaching and enabled visual programming for motion authoring.
BULLET: [ACM IMWUT 2023] E3D: An AI-assisted design space for 3D-printable kinetic sensors from smartwatch demonstrations. Trained an LSTM-based IMU classifier to map interactions to parametric designs with 98.9% accuracy.

ITEM: Multimodal Agentic AI for Generative 3D Mechanism Design
BULLET: [ACM CHI 2026] EUREXA: A diagnose–discover–describe multimodal agentic framework for interpreting vague user context and generating 3D mechanism designs. Introduced a vagueness quantification metric and used RAG, few-shot learning, in-context learning, and ReAct to achieve a 60% gain over state-of-the-art methods in diagnosis and design generation.

ITEM: Interaction Modeling and Behavioral Inference from Context-Aware Sensing
BULLET: [Work in progress] Developed a multi-agent framework for long- and short-term interaction modeling and behavioral inference, integrating spatiotemporal learning, RAG, LLMs, and MCP. Introduced physical interactions as an input modality for distributed sensor interpretation without hard thresholds, achieving 83.3% interpretation accuracy and capturing lifecycle-aware affordances for adaptive interventions.
BULLET: [ACM MobileHCI 2026] Developed an agentic VLM to detect object–interaction–induced vibrations and generate structured 3D sensor designs using LLaMA 3.2-Vision, prompt engineering, in-context learning, and MCP, achieving 91.4% accuracy.

ITEM: Task-Specific AI for Efficient Prediction and Edge Deployment
BULLET: [Automation in Construction 2026] Developed an edge-deployed electrotactile haptic framework for excavation safety using dual-IMU sensing and ML-based inverse mapping. Achieved 93.83% accuracy with sub-100 ms latency.
BULLET: [M.Sc. thesis; submitted to IEEE Sensors 2026] Developed a lightweight hybrid residual network for railway fastener health detection and curated a real-world dataset of 9.2K images. Achieved 97.11% accuracy (F1 = 0.969), 97.5 FPS, and 10.25 ms latency, with 49.5% lower latency and 99.2% fewer parameters than ResNet-18.
BULLET: [IEEE WIECON-ECE 2023] Developed a domain-adaptive deep neural network for precipitation prediction, achieving up to 43.51% MAPE reduction across unseen locations.
